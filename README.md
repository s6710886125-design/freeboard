# Smart Farm IoT-125 — โรงเรือนอัจฉริยะแบบเรียลไทม์

ระบบ IoT ที่ใช้ **ESP32 + ESPHome** จำลองค่าเซนเซอร์ในโรงเรือน แล้วส่งขึ้น **Firebase Realtime Database (`iot-125`)**
และแสดงผลแบบเรียลไทม์บน Dashboard ที่โฮสต์ด้วย **GitHub Pages** (`/freeboard`)

```
ESP32 (ESPHome) ──► Firebase RTDB: iot-125
                      ├── latest    (PUT ทุก 5 วินาที — ค่าล่าสุด)
                      ├── history   (POST ทุก 10 วินาที — ข้อมูลย้อนหลัง)
                      └── control   (Dashboard เขียน → ESP32 อ่านทุก 10 วินาที)
                              │
                              ▼
                 GitHub Pages /freeboard (index.html) ──► Web Dashboard
```

## ข้อมูลที่ส่งขึ้น Firebase (18 คอลัมน์)

| คอลัมน์ | ความหมาย | หน่วย |
|---|---|---|
| `temperature` | อุณหภูมิอากาศ | °C |
| `humidity` | ความชื้นสัมพัทธ์ในอากาศ | % |
| `soil_moisture` | ความชื้นในดิน | % |
| `light` | ความเข้มแสง | lux |
| `co2` | ก๊าซคาร์บอนไดออกไซด์ | ppm |
| `soil_ph` | ค่า pH ของดิน | pH |
| `water_level` | ระดับน้ำในถังเก็บน้ำ | % |
| `pump` | สถานะปั๊มรดน้ำ | true/false |
| `refill` | วาล์วเติมน้ำเข้าถังกำลังทำงาน | true/false |
| `mode` | โหมดปั๊ม `auto` / `manual` | — |
| `soil_low`, `soil_high` | เกณฑ์เริ่ม/หยุดรดน้ำที่อุปกรณ์ใช้อยู่ | % |
| `rssi` | ความแรงสัญญาณ Wi-Fi (ค่าจริงจาก ESP32) | dBm |
| `uptime` | เวลาที่อุปกรณ์เปิดมา (ค่าจริง) | วินาที |
| `device`, `seq` | ชื่ออุปกรณ์ / ลำดับแพ็กเก็ต | — |
| `time` | เวลาจาก SNTP ของอุปกรณ์ (Asia/Bangkok) | — |
| `ts` | เวลาเซิร์ฟเวอร์ Firebase (`{".sv":"timestamp"}`) | ms |

ค่าเซนเซอร์จำลองแบบ **random walk** ผูกกับเวลาจริงของวัน (กลางวันร้อน-แดดแรง-CO₂ ลด, กลางคืนเย็น-ชื้น)
ความชื้นดินลดลงตามการระเหย และเพิ่มขึ้นเมื่อปั๊มทำงาน → เห็นวงจรรดน้ำอัตโนมัติจริงบนกราฟ

## ความสามารถของ Dashboard

- ค่าทุกเซนเซอร์แบบเรียลไทม์ พร้อมสถานะ ปกติ / เฝ้าระวัง / วิกฤต และกราฟเล็ก (sparkline)
- **คะแนนสภาพแวดล้อมโรงเรือน** + คำแนะนำสิ่งที่ควรทำ (เช่น พ่นหมอก พรางแสง เติมน้ำ ปรับ pH)
- **ควบคุมปั๊มรดน้ำจากหน้าเว็บ** (Auto/Manual, เปิด-ปิดปั๊ม, ตั้งเกณฑ์ความชื้นดิน) ผ่าน `/control`
- ค่าทางการเกษตรที่คำนวณเอง: **VPD**, จุดน้ำค้าง, ดัชนีความร้อน
- กราฟย้อนหลัง 10 นาที – 3 ชั่วโมง, บันทึกเหตุการณ์อัตโนมัติ, แจ้งเตือนบนเบราว์เซอร์เมื่อวิกฤต
- ตรวจสถานะอุปกรณ์ออนไลน์/ออฟไลน์, ดาวน์โหลดข้อมูลย้อนหลังเป็น CSV, ธีมสว่าง/มืด, รองรับมือถือ

## ไฟล์

- `index.html` — Dashboard (Firebase JS SDK + Chart.js)
- `iot-125.yaml` — คอนฟิก ESPHome สำหรับ ESP32 (Wi-Fi อยู่ใน `secrets.yaml` ที่ไม่ได้อัปโหลด)
